# 老朽キュービクル（高圧受変電設備）・業務用空調 一括判定シミュレーター

**2027年3月31日 低濃度PCB処分期限 × 2026年1月 工作物アスベスト事前調査義務 × 2026年度 第三次トップランナー省エネ補助金** を1画面で同時判定し、工場・倉庫・商業ビルの施設管理者・総務部長がそのまま役員決裁に回せる **A4社内稟議レポート（PDF）** を出力するB2B技術法規・投資採算シミュレーターです。

## 1. 解決する現場課題（3大法改正・制度の同時到来）

1. **PCB特別措置法（2027年3月31日 低濃度PCB廃棄物 計画的処理完了期限）**
   - 1972年以前製造の「高濃度PCBリスク（期限経過済・緊急対応要）」と、メーカーごとに異なる出荷時「低濃度PCB混入可能性期間（日立・三菱・東芝・富士・明電舎：〜1990年、ダイヘン：〜1991年、日新電機：〜1994年3月等）」および絶縁油交換履歴注意期間を自動判定。
2. **改正大気汚染防止法・石綿障害予防規則（2026年1月1日 工作物石綿事前調査 完全義務化）**
   - 2006年8月以前製造・設置の受変電設備（フランジガスケット・耐火パテ・絶縁板・防錆塗装）および業務用空調（配管パッキン・保温材）の撤去・更新工事における有資格者調査義務と、請負金額100万円以上のGビズID電子報告義務を判定。
3. **2026年度 第三次トップランナー変圧器基準（JIS C 4304 / 4306）＆ 省エネ補助金**
   - `50kVA〜1000kVA` の油入・モールド変圧器における旧世代機と2026基準機（高配向性電磁鋼板／超高効率アモルファス）の**無負荷損（鉄損 $W_0$）＋負荷損（銅損 $W_c$）**を実効負荷率に応じて厳密計算し、経産省SII「省エネルギー投資促進支援事業（設備1/3補助）」＋全47都道府県の中小企業加算を反映した実質投資回収年数と10年間累積損益グラフを出力します。

## 3. ローカル起動と検証手順

外部パッケージ不要（Python 3標準ライブラリのみ）で即座に検証・プレビューできます。

```powershell
# 1. ルールエンジンの構文チェック＆自己検証実行（site/data/equipment_rules.json を更新）
python -m py_compile pipeline/cubicle_RuleEngine.py
python pipeline/cubicle_RuleEngine.py

# 2. ローカルWebサーバーでシミュレーターを起動（http://localhost:8090）
python -m http.server 8090 --directory site
```

## 4. マネタイズ設定（特定商取引法表記 不要のB2B送客モデル）

本ツールはサイト上で直接課金・物品販売を行わず、無料技術試算と引き換えに電気工事・電気保安法人・業務用空調専門業者へ無料現地調査・見積もり依頼を送客する構成のため、個人の住所・電話番号公開（特商法表記）なしで運用可能です。

`site/data/cta_config.json`（および `data/cta_config.json`）の `"active_mode"` を書き換えるだけで送客チャネルを切り替えられます：

- `"partner_form"`（推奨）：提携する第一種電気工事会社・空調設備工事会社の受付フォーム（Googleフォーム / Formrun等）へ診断パラメータ（設備種別・メーカー・年式・容量・PCB判定コード・都道府県）をURLクエリ付与して送客。
- `"a8_affiliate"`：A8.net の業務用エアコン一括見積もり・法人省エネ相談プログラムURLへ送客（自動でステマ規制対応の `PR・提携専門業者ご案内` バッジを表示）。
- `"rentracks_affiliate"`：レントラックスのクローズド高単価B2B設備案件URLへ送客。

## 5. 損失電力量・投資回収の計算式根拠

- **変圧器 年間損失電力量（JIS C 4304 / JIS C 4306 準拠）**
  $$E_{\text{loss}} \, [\text{kWh/年}] = \frac{W_0 + \left(\frac{m}{100}\right)^2 \cdot W_c}{1000} \times 8760 \, \text{h} \times N_{\text{台}}$$
  - $W_0$：無負荷損（鉄損）[W]（通電中は24時間365日発生）
  - $W_c$：定格負荷損（銅損）[W]
  - $m$：平均実効負荷率 [%]
- **業務用パッケージ空調 年間消費電力量**
  $$E_{\text{hvac}} \, [\text{kWh/年}] = \frac{Q_{\text{cool}} \, [\text{kW}] \times \left(\frac{m}{100}\right) \times 2600 \, \text{h}}{\text{APF}} \times N_{\text{系統}}$$
